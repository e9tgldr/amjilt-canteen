логик дотор холбогдсон, бүрэн ажилладаг прототип.

## Шалгалт

```
node verify.js
```

Дэлгэц бүр зөв ачаалагдаж байгаа, бүх шилжилт бодит дэлгэцэд хүрнэ, бүх товч
нэртэй, бүх тоо хоорондоо нийцнэ гэдгийг шалгана. Одоо **38 дэлгэц, 89 шилжилт,
62 товч — бүгд зөв**.

## Ажиллаж байгаа үнэхээр

- Менюнд хайх, ангиар шүүх, дуртай хоолд шүүх — бодит үр дүн
- Сагсны тоо ± товч, нийлбэр дүн хэвээрээ шинэчлэгдэнэ
- Авах цаг сонгоход сул орон тоо өөрчлөгдөнө (16 сул бүр)
- Smart Queue дүүрсэн цагийг сонгох боломжгүй
- Төлбөрийн төлөв: боловсруулж байна → амжилттай → амжилтгүй
- QR кодын гурван төлөв
- Захиалгын 5 үе шат дараалан шилжинэ
- Гал тогооны самбар дэх карт баганаас багананд шилжинэ
- Агуулах, хоолны хуваарилалтын шалгалт шууд хувьсагч
- Хүнсний харшил сонговол холбогдох хоолд анхааруулга гарна
- Эцэг эхийн өдрийн лимит 70%-аас давбал улаан, 100%-аас давбал улаан өнгөөр

## Figma руу авах

Дараах хоёр зам байна. Хоёул ажиллана.

### 1. Зураг оруулах — яг одоо

`export/` хүрвээр дээрх 38 PNG бүх дэлгэцийн 2× хэмжээтэй зураг.
Figma дээр шинэ файл үүсгээд зүүрэгнэ — бүрэн бүтэн, ямар ч нэмэлт ажилгүй.

Файл зориулалтын дагуу:
- `01`–`31` — утасны дэлгэцүүд (390×844)
- `32`–`36` — таблет (1024×768)
- `37`–`38` — десктоп (1440×900)

### 2. Plugin — жинхэнэ компонент

Figma дээр зураг биш, **найдвартай Figma** хэрэгтэй: Variable, компонент,
variant, Auto Layout бүхий.

1. Figma **десктоп** программыг нээнэ (браузер дотор ажиллахгүй)
2. `Plugins → Development → Import plugin from manifest…`
3. `figma-plugin/manifest.json` файлыг сонгоно
4. **Design file** нэгтэй нэгэн: `File → New design file`
5. Тэр файл дээр үлсэн **Plugins → Amjilt Canteen — Design System Builder**
6. **Үүсгэх** товч

Үүсгэхэд:
- `Amjilt / Color`, `Amjilt / Spacing`, `Amjilt / Radius` — Variable цуглуулалт
- `01 — Design System` — өнгө, үсэг, зай, радиусын хуудас
- Компонент: `Button` (4×3), `Slot` (5 төлөв), `OrderCard` (4), `StatTile` (4),
  `Input` (4) — бүгд variant бүхий
- `02 — Student App`, `04 — Cafeteria` — үндсэн дэлгэцүүд

> Slides болон FigJam файлд ажиллахгүй. Plugin эхнээжид шалгаж, зөвшөөрөхгүй
> бол мэдэгдэл гаргана.

**Зөвхөн нэг удаагийн тэмдэглэгээ:** plugin-ийн QR код болон захиалгын дүрсийг
placeholder хэлбэрээр байгуулдаг. Үнэхээр ашиглах үед бодит зураг солих хэрэгтэй.
